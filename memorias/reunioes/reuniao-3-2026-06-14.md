### D42 — Autenticação

| # | Decisão | Escolha |
|---|---------|---------|
| D42 | Tipo | Sessão salva no SQLite (express-session + connect-sqlite3) |
| D43 | Por que não JWT | Mais complexo, 1 usuário não precisa, cold start losing sessions seria problema se em memória |
| D44 | Armazenamento | SQLite — resiliente a restarts do Render Free Tier |

### D45 — Navegação cruzada em Projetos

| # | Decisão | Escolha |
|---|---------|---------|
| D45 | Abordagem | Filtro/etiqueta — itens com `projeto_id` aparecem no projeto |
| D46 | Itens sem projeto | Existem soltos nos seus módulos (Tarefas, Notas) |
| D47 | Itens com projeto | Aparecem tanto no módulo original quanto na aba do Projeto |
| D48 | Criação | Pode criar tarefa/nota dentro do Projeto (recebe projeto_id automaticamente) |
| D49 | Consistência | Editar em qualquer lugar reflete no outro (mesmo registro no banco) |

### D50 — Notas soltas vs Notas em projetos

| # | Decisão | Escolha |
|---|---------|---------|
| D50 | Resolução | Ambas existem — nota sem `projeto_id` = solta, com `projeto_id` = vinculada ao projeto |
| D51 | Migrabilidade | Nota solta pode ser vinculada a um projeto depois |

### D52 — Hub Cards (conteúdo dos cards do centro de comando)

| Módulo | Card mostra |
|--------|------------|
| Finanças | Saldo do mês atual + último lançamento |
| Tarefas | Total pendentes + próximas 3 com vencimento próximo |
| Metas | Top 3 metas com maior progresso |
| Cronograma | Próximos eventos de hoje/amanhã |
| Notas | Últimas 3 notas editadas |
| Hábitos | Streak atual + quantos hábitos feitos hoje |
| Projetos | Projetos ativos (em andamento) |

D53: Cards são compactos (widget style), expansíveis no futuro.

### D54 — Layout Mobile dos Módulos

| Módulo | Layout mobile |
|--------|-------------|
| Geral | Sidebar some, header fixo com botão voltar Hub, conteúdo full-screen |
| Finanças | Abas deslizáveis (resumo, extrato, fixas, invest.) + lista de lançamentos |
| Tarefas | Alternância lista/Kanban — Kanban vira colunas com swipe horizontal |
| Metas | Lista vertical com barra de progresso |
| Cronograma | Versão dia como padrão + swipe para mudar dia |
| Notas | Lista de notas → toque abre editor em tela cheia |
| Hábitos | Checklist simples + mapa de calor compacto |
| Projetos | Abas empilhadas verticalmente (scroll) ao invés de lado a lado |

### D55 — Configurações (⚙)

| Seção | O que configura |
|-------|---------------|
| Perfil | Nome do usuário, avatar (emoji ou inicial), alterar senha |
| Aparência | Toggle dark/light (hoje só dark, deixa pronto) |
| Finanças | Moeda (R$), categorias personalizadas, perfis de orçamento |
| Cronograma | Fuso horário, início da semana (dom/seg) |
| Hábitos | Horário de corte do dia (quando hábitos resetam) |
| Exportar | Exportar dados em JSON/CSV (backup) |
| Sobre | Versão do app, créditos |
